## 🎓 **Tutorial Cepat**

### **Menggunakan Portal OPTK:**
1. Buka [Portal OPTK](https://azizahsiti99999-blip.github.io/portal-optk/)
2. Klik tombol **"Kelola Database OPTK"** di pojok kanan bawah
3. Isi form dengan data OPTK baru
4. Klik **"Tambah Data OPTK Baru"**
5. Data akan tersimpan otomatis di browser

### **Menggunakan TodoList Pro:**
1. Buka [TodoList Pro](https://azizahsiti99999-blip.github.io/portal-optk/todolist.html)
2. Masukkan tugas di input field
3. Pilih kategori dari dropdown
4. Klik tombol **"Add"**
5. Tugas akan muncul di list
6. Gunakan filter dan sort sesuai kebutuhan
7. Buka Settings untuk export atau clear data

---

## ⚡ **Tips & Trik**

- 💡 Gunakan kategori untuk mengorganisir tugas
- 💡 Set prioritas tinggi untuk tugas urgent
- 💡 Export tugas Anda untuk backup
- 💡 Gunakan filter untuk fokus pada tugas aktif
- 💡 Data Anda aman di browser lokal Anda
