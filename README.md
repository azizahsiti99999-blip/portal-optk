# Portal OPTK - Biosekuriti Penternakan & Karantina Veterinar

Sistem terintegrasi untuk pengamanan kesihatan haiwan & tumbuhan berstandar WOAH, dengan database OPTK (Organisme Pengganggu Tumbuhan Karantina) yang dapat dikelola secara real-time.

## 🌐 Akses Web

**Web sudah live dan bisa diakses di:**

👉 **https://azizahsiti99999-blip.github.io/portal-optk/**

## ✨ Fitur Utama

### 1. **Biosekuriti Penternakan**
   - Zona sanitasi dan pengendalian masuk
   - Desinfeksi kendaraan otomatis
   - Protokol ketat untuk mencegah penyakit menular

### 2. **Karantina Veterinar**
   - Pemeriksaan klinis dan laboratorium
   - Tindakan perlakuan dan penolakan
   - SOP pengawasan lintas batas

### 3. **Database OPTK (Organisme Pengganggu Tumbuhan Karantina)**
   - ✅ **Data persisten** - tidak hilang saat refresh halaman
   - Tambah data OPTK baru melalui modal form
   - Hapus data yang tidak diperlukan
   - Cari/filter OPTK berdasarkan nama atau kode
   - Status golongan A1 (belum ada) dan A2 (sudah ada di wilayah tertentu)

### 4. **Mode Edit Teks**
   - Edit semua teks di halaman secara langsung
   - Perubahan tersimpan di browser Anda
   - Tombol floating action di pojok kanan bawah

## 💾 Penyimpanan Data

Data OPTK yang Anda tambahkan disimpan menggunakan **localStorage browser** sehingga:
- ✅ Data tetap ada meski halaman di-refresh
- ✅ Data tersimpan lokal di device Anda
- ⚠️ Data hilang jika Anda hapus browser cache/cookies

## 🚀 Cara Menggunakan

1. **Akses halaman:** https://azizahsiti99999-blip.github.io/portal-optk/
2. **Tambah OPTK baru:** Klik tombol "Kelola Database OPTK" → Isi form → Klik "Tambah Data OPTK Baru"
3. **Hapus OPTK:** Klik tombol "Hapus" di baris data yang ingin dihapus
4. **Cari OPTK:** Gunakan search box untuk mencari berdasarkan nama atau kode
5. **Edit teks:** Klik "Mode Edit Semua Teks & Foto" untuk mengubah konten
